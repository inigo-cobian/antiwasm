# antiwasm
An objdump for WebAssembly (WIP).

Current usage:
`antiwasm [args] --filename [file.wasm]`

Current args:

`--help`: displays help.

`--debug`: Debug mode.

`--verbose`: Verbose mode.

`--pedantic`: Pedantic mode
